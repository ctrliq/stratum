## Method

- Completeness pass first: behavior inventory built from `src/resources.jsx`, `src/ui/resource-list.jsx`, `src/ui/codeview.jsx`, `src/screens/tabbed.jsx`, `PaneShell`/`Modal`/`StatusPill` in `src/ui/shell.jsx` and the routing parts of `src/app.jsx`, in both roots, before any `.feature` file was opened.
- Citations: all 138 scenarios carry `# source:` lines; every cited file exists and every line range is inside the file (checked mechanically), and every scenario's tags match the roots it cites.
- Sampling: no sampling. Every scenario was read against its cited ranges in both roots. Every `# assumption:` scenario, every `@diverged` pair and every Examples row was re-derived from code; the Age rows and the YAML rows were also executed against the legacy functions (`age`, `toYaml`/`yamlScalar`).
- Not counted as gaps because another domain covers them: the unknown-route placeholder and the extension seam's reserved route ids (`shell/routing.feature`, `shell/extension-seam.feature`), badge colours (`shell/shared-chrome.feature`), Scale/Restart/pod actions (`workloads/`), `?tab=` (`storage/`, `access/`).
- Declared out of scope by `NOTES.md` and therefore not counted: the list/detail split (resizable divider, detail pane hidden when nothing is open, single pane below 820px), syntax colouring.
- No scenario describes implementation rather than behavior.
- Every source file under the domain's paths is cited by at least one scenario.
