# Stratum PRO

Stratum PRO is a commercial edition of Stratum, shipped as its own `stratum`
binary and built from the same engine. This page lists what each edition
includes.

## Stratum and Stratum PRO

| Capability | Stratum | Stratum PRO |
|---|---|---|
| One-binary Kubernetes distribution | ✓ | ✓ |
| Airgap install | ✓ | ✓ |
| HA control plane and etcd membership | ✓ | ✓ |
| Rolling upgrades and rollback | ✓ | ✓ |
| etcd snapshot and restore | ✓ | ✓ |
| Single-cluster dashboard | ✓ | ✓ |
| Model Context Protocol (MCP) server for AI agents | ✓ | ✓ |
| CIS hardening profile and `hardening check` | — | ✓ |
| Many clusters from one hub | — | ✓ |
| Registering an existing cluster | — | ✓ |
| Single sign-on | — | ✓ |
| Provisioning new clusters | — | ✓ |
