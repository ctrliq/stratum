# Layer membership for the module's internal/... packages. An internal
# package may import only packages of its own or a strictly lower layer;
# same-layer imports are legal on purpose (the orchestration packages share
# each other), and every upward import is either fixed or recorded as a
# reviewed exception in tools/importlayers/exceptions.txt. One
# `layer<N> <import-path-prefix>` rule per line, longest prefix wins; a
# package matching no rule, and a rule matching no package, both fail the
# guard (tools/importlayers), so this table and the tree cannot drift apart.
#
# The layers are assignments of purpose, not a sorting of today's imports:
# a package sits where its job belongs, and an import that fights that
# assignment is the thing the guard exists to catch.

# phase state machine, the cluster-id verifier, the environment and lookup
